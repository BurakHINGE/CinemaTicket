## 🇬🇧 English

This project is a **simple console-based cinema ticket reservation system** developed in Java.

The seating layout is implemented using a 2D array.  
Users can select available seats, and once a seat is chosen, it is marked as occupied in the system.

The purpose of this project is to practice:

- Two-dimensional arrays (2D arrays)  
- Nested loops  
- Conditional logic  
- Console-based interaction flow  

The system prevents selecting already occupied seats and updates the seating layout dynamically after each reservation.

---

# ✨ Features

- 🎟 Seat selection system  
- 🪑 2D array-based seating layout  
- ✅ Occupied seat marking  
- ❌ Prevents double booking  
- 🔁 Dynamic seat status updates  
- 🖥 Console-based interface

## 🇹🇷 Türkçe

Bu proje, Java ile geliştirilmiş **konsol tabanlı basit bir sinema bileti rezervasyon sistemidir**.

Oturma düzeni 2 boyutlu dizi (2D array) kullanılarak oluşturulmuştur.  
Kullanıcı boş koltukları seçebilir ve seçilen koltuk sistem tarafından dolu olarak işaretlenir.

Projenin amacı:

- 2 boyutlu dizileri (2D array) öğrenmek  
- İç içe döngü (nested loop) kullanımı  
- Koşul yapıları ile kontrol mekanizması kurmak  
- Konsol uygulama akışını yönetmek  

Sistem, dolu koltukların tekrar seçilmesini engeller ve her rezervasyon sonrası oturma planını günceller.
